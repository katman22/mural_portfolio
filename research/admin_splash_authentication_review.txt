Whare Pūmanawa admin splash: authentication decision required

No application implementation or authentication changes have been made.

Current authentication:
GET /admin -> Admin::DashboardController#index -> Admin::BaseController.
Credentials come exclusively from ADMIN_USER and ADMIN_PASSWORD.
Both values use secure comparison; missing configuration returns 503.
Missing/incorrect HTTP Basic credentials return 401 with WWW-Authenticate.
No User model, account records or authentication session tables exist.
Passwords already match the Rails parameter filter.

Tradeoff:
An ordinary HTML form submits a request body; HTTP Basic expects Authorization
headers on protected requests. A successful form POST does not establish the
browser's Basic authentication state for later navigation. Rails has no standard
form-to-browser-Basic bridge. JavaScript/manual header management or credentials
in URLs would conflict with the approved scope and progressive enhancement.
Reference: https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Authentication

Option 1 — preserve HTTP Basic exactly:
Public GET /admin/login artistic splash with an Enter administration action.
Action links to existing /admin; browser-native credential prompt remains.
No HTML username/password fields pretending to establish a login.

Option 2 — intentional HTML form (requires explicit architecture approval):
GET /admin/login renders form; POST /admin/login checks environment credentials;
DELETE /admin/logout clears an expiring authenticated cookie.
Use Rails encrypted/signed cookie containing only an authorization marker,
expiry and credential-version binding, never the submitted password.
Require CSRF protection, HttpOnly, SameSite, Secure in production, secure
credential comparison, cache prevention and appropriate login attempt limiting.
Retain HTTP Basic as an alternative if requested.
No users/accounts/session table or authentication gem. However the cookie is
client-held authentication state and changes the current Basic-only architecture.
Do not implement this without approval.
