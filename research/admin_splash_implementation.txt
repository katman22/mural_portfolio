Whare Pūmanawa admin splash and persistent authentication

Completed scope:
Replaced HTTP Basic with PostgreSQL User and Rails encrypted CookieStore sessions.
No second authentication system remains. No mural gallery or admin CRUD.

Routes:
GET /admin/login -> Admin::SessionsController#new
POST /admin/login -> #create
DELETE /admin/logout -> #destroy
GET /admin -> Admin::DashboardController#index, gated by Admin::BaseController

User:
username normalized with strip/downcase, required, unique validation and DB index;
password_digest required; bcrypt 3.1.22 via has_secure_password reset_token: false;
active NOT NULL/default true; timestamps. DB checks reject empty/unnormalized
username and empty password digest. Password minimum 12 characters, native bcrypt
maximum 72 bytes. No signup, reset tokens, recovery, roles, remember-me or profile UI.

Authentication:
Rails authenticate_by performs dummy password hashing for unknown usernames.
Unknown username, wrong password and inactive user get identical generic error.
Successful login resets session before assigning user_id and redirects to /admin.
Logout resets session. Each protected request checks user exists and is active.
Normal CookieStore with unique key; HttpOnly, SameSite=Lax, Secure in production.
Cookie holds user ID, not password. Rails CSRF checks retained. Auth pages no-store;
login layout excludes Turbo/JS and form works through ordinary HTML POST.
Native per-IP rate limit: 10 attempts / 3 minutes using 1 MB process-local memory.
Not shared across workers and reset on restart; no Redis/new infrastructure.

Bootstrap:
README documents production Rails console using STDIN.getpass and trailing nil
to suppress console echo. No hard-coded/default passwords, seed credentials,
production user or real development user was created by implementation.
Run migrations and console only against the mural application's own DATABASE_URL.
Do not type real passwords as command literals or commit them.

Design:
Warm off-white, charcoal, deep red; system typography and editorial whitespace.
Large artwork alongside form above 760px; vertically stacked below that breakpoint.
Seven supplied static assets in explicit ARTWORK pool; one selected each render.
No Mural association, image processing, rotation, timers, carousel or selection JS.
object-fit: contain preserves both aspect ratios, with neutral letterboxing.
Mobile artwork is bounded to 180–300px; controls at least 48px tall.
Real labels, autocomplete, password input, focus outline, error alert/descriptions.
Decorative artwork/mark have empty alt; small replaceable red/black SVG curve.
No animations or external fonts. Footer uses approved Māori welcome text.
